# Zombie Survivor

Unity 기반 모바일 좀비 생존 액션 게임. 프로젝트 이름은 가칭이다.

플레이어는 몰려오는 좀비를 피하면서 자동으로 사격하고, 상황에 맞게 무기를 교체한다.

- [게임 설계 문서](docs/GAME_DESIGN.md)
- [프로젝트 작업 지침](AGENTS.md)
- [Codex 작업 지침](codex.md)
- [작업 기록과 남은 작업](todo.md)
- 현재 단계: Unity 6000.3.27f2 라이선스 확인, 패키지 복원·C# 컴파일·Arena 씬 생성 완료
- 다음 단계: 권총·산탄총, 자동 조준·사격과 무기 교체 구현

이동·카메라 소스와 URP 테스트 씬을 구성했다. 플레이 모드에서 키보드 이동·정지·맵 경계·카메라 추적 자동 검증을 통과했다. 화면 시각 확인과 모바일 터치·Android 빌드는 아직 미검증이다. [초기 설정 안내](docs/SETUP.md)를 참고한다.

일반 좀비의 화면 밖 생성·추적, 접촉 피해·무적 시간, 사망과 재시작을 구현하고 플레이 모드 자동 검증을 통과했다. Arena는 바로 시작하며 사망 후 버튼 또는 R로 재시작한다. 무기와 3분 승리 조건은 아직 구현 전이다.
