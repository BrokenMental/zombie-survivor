# Zombie Survivor

Unity 기반 모바일 좀비 생존 액션 게임. 프로젝트 이름은 가칭이다.

플레이어는 몰려오는 좀비를 피하면서 자동으로 사격하고, 상황에 맞게 무기를 교체한다.

- [게임 설계 문서](docs/GAME_DESIGN.md)
- [프로젝트 작업 지침](AGENTS.md)
- [Codex 작업 지침](codex.md)
- [작업 기록과 남은 작업](todo.md)
- 현재 단계: 이동·전투·웨이브·3분 승패 흐름 구현과 플레이 모드 자동 검증 완료
- 다음 단계: 실제 3분 플레이·모바일 조작 확인, 기준 Android 기기 선정과 성능 측정

이동·카메라 소스와 URP 테스트 씬을 구성했다. 플레이 모드에서 키보드 이동·정지·맵 경계·카메라 추적 자동 검증을 통과했다. 화면 시각 확인과 모바일 터치·Android 빌드는 아직 미검증이다. [초기 설정 안내](docs/SETUP.md)를 참고한다.

일반·빠른 좀비, 시간대별 웨이브, 권총·산탄총 자동 사격, 피해·무적 시간과 3분 생존 승리를 구현했다. Arena에서 Start 또는 Enter로 시작하고 Space·오른쪽 아래 버튼으로 무기를 교체한다. 결과에는 승패·생존 시간·처치 수를 표시하며 Restart/R 또는 Title로 이동한다. 이동·피해·무기·게임 흐름 자동 검증을 통과했으며 실제 3분 연속 플레이와 실기기 검증은 남아 있다.
