# Zombie Survivor

Unity 기반 모바일 좀비 생존 액션 게임. 프로젝트 이름은 가칭이다.

플레이어는 몰려오는 좀비를 피하면서 자동으로 사격하고, 상황에 맞게 무기를 교체한다.

- [게임 설계 문서](docs/GAME_DESIGN.md)
- [프로젝트 작업 지침](AGENTS.md)
- [Codex 작업 지침](codex.md)
- [작업 기록과 남은 작업](todo.md)
- [Android 에뮬레이터 검증 결과](docs/VALIDATION_20261103.md)
- 현재 단계: 이동·전투·웨이브·3분 승패 흐름 구현과 플레이 모드 자동 검증 완료
- 다음 단계: 일반 규칙 생존 난이도·타격감 평가와 성능 원인 분석. 실제 휴대폰 검증은 사용자 요청으로 보류.

이동·카메라와 URP 테스트 씬을 구성했다. 키보드·터치 이동과 전투·승패 자동 검증을 통과했고 Android 개발 APK를 빌드해 에뮬레이터의 화면·터치를 확인했다. [초기 설정 안내](docs/SETUP.md)를 참고한다.

일반·빠른 좀비·웨이브·권총·산탄총과 3분 승패를 구현했다. Start/Enter로 시작하고 Space·오른쪽 아래 버튼으로 무기를 교체한다. 결과에서 Restart/R·Title을 선택한다. 일반 규칙 자동 조작은 125초에 패배했고, 개발 전용 고체력 조건에서는 실제 180초 승리 전환을 확인했다. 별도 100마리 부하 측정은 약 10~13fps로 에뮬레이터에서 60fps 목표를 달성하지 못했다.
