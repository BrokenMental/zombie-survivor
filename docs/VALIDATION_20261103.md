# Android 에뮬레이터 실행 검증 — 2026-11-03

## 환경과 범위

- Unity 6000.3.27f2, URP 17.3.0, Input System 1.20.1.
- ARM64 IL2CPP Development APK, 패키지 `com.zombiesurvivor.prototype`.
- 프로젝트 전용 Android 16/API 36 x86_64 에뮬레이터, 1080×2400 세로 화면, RAM 2048MB, SwiftShader 소프트웨어 GPU, ARM64 변환 실행.
- 기존 Pixel_Tablet는 저장 공간 부족으로 설치가 실패해 사용하지 않았다. 기존 앱·데이터를 지우지 않고 `Builds/Avd`에 별도 AVD를 생성했다.
- 사용자 요청으로 실제 휴대폰 검증은 후속으로 보류했다. 아래 수치를 휴대폰 GPU·발열·배터리 성능으로 해석하지 않는다.

## 수정 및 기능 확인

- 고밀도 화면에서 작게 보이던 IMGUI를 안전 영역과 논리 폭480 기준으로 확대하고 HUD를 두 줄로 정리했다. 잘리는 조작 안내 문구도 줄였다.
- 첫 누름과 이동이 한 프레임에 들어오면 조이스틱 기준점이 이동 좌표로 잡히던 문제를 `touch.startPosition` 사용으로 수정했다. 화면 밖으로 나가는 조이스틱 표시도 제한했다.
- 같은 프레임의 누름·이동과 해제 후 정지를 Input System 터치 상태 이벤트로 회귀 검증했다.
- Android APK 빌드와 설치·실행, 터치 Start·이동·산탄총/권총 전환, 패배 결과 표시를 확인했다.
- 빌드 후 `TOUCH/SESSION/WEAPON/ENCOUNTER/MOVEMENT VERIFICATION PASSED`, Unity 종료0을 확인했다. 마지막 문구·개발 계측 보완 후 최종 APK도 빌드 종료0이다.
- 개발 빌드에만 프레임 간격·메모리 계측과 `zs_soak`, `zs_stress` 진입을 추가했다. 일반 실행에서는 두 모드가 모두 꺼져 있고 정식 비개발 빌드에는 계측 코드가 포함되지 않는다.
- Android JNI 내장 모듈1.0.0과 ARM64 IL2CPP·패키지 ID를 설정했다. 첫 Android 빌드가 채운 URP 기본 프로필·런타임 리소스·셰이더 필터 설정을 함께 보존한다.

- Soak: 개발 전용 체력10억, 무적0초, 정상 생성·사격·실제 프레임 타이머로180초 승리 전환 확인. 게임 시간을 건너뛰지 않는다.

## 재현과 로컬 산출물

Unity 실행 파일에 다음 인수를 전달하면 개발 APK를 빌드한다.

```text
-batchmode -nographics -quit -buildTarget Android -projectPath C:\dev\zombie-survivor -executeMethod ZombieSurvivor.Editor.BuildAndroid.Development -logFile C:\dev\zombie-survivor\unity-android-package.log
```

빌드와 플레이 회귀를 함께 실행하려면 `DevelopmentAndVerify`를 사용하고 `-quit`은 제외한다. 플레이 검증이 직접 종료한다.

설치·실행 후 터치 조작은 `tools/Play-Android.ps1 -Serial 127.0.0.1:5571 -Continuous`로 재현한다. 이 스크립트는1080×2400 기준이며 다른 기기에 그대로 적용하지 않는다. 개발 진단은 `tools/Measure-Android.ps1 -Mode Soak` 또는 `-Mode Stress`로 실행한다. 진단 스크립트는 해당 패키지만 종료 후 다시 시작한다.

- APK: `Builds/Android/ZombieSurvivor-development.apk`.
- 최종 APK 크기70,301,412바이트, SHA-256 `438091C025485030B0A57B0BD99DAD0170EFF924F3BFA459DB6936583D709E94`. Unity 빌드 보고서의 총 산출물 용량은 APK 파일 크기와 다르다.
- 일반 규칙 로그: `Builds/Validation/normal-final-unity.log`.
- 터치·타이틀·결과 화면: `Builds/Validation`의 PNG.
- 연속 실행·부하 로그/화면/메모리: `soak-*`, `stress-*`와 각 PNG.
- APK·AVD·원시 로그·화면·빌드 캐시는 Git에서 제외한다. 이 문서와 재현 도구는 버전 관리한다.
- 최종 APK의 일반 실행에서 체력100·터치 이동·산탄총 전환과 축약 안내 문구를 다시 확인했다. 검증 전용 에뮬레이터는 작업 후 종료했고 기존 에뮬레이터는 유지했다.

## 남은 확인

- 실제 휴대폰의60fps·100마리 성능, 발열과 장시간 메모리, 배터리: 사용자 요청으로 보류.
- 일반 규칙180초 생존과 무기별 효용·타격감·난이도: 사람의 플레이 평가 필요.
- 여러 손가락 동시 조작, 앱 전환·복귀와 실제 노치·화면 비율: 후속 확인.
- 기존 Unity 에디터 SearchDatabase 예외는 별도 기록 대상으로 남는다. SwiftShader에서 지원하지 않는 일부 URP 디버그 셰이더 경고도 발생했으며 일반·빠른 적과 기본 전투 화면의 렌더링은 확인했다.
